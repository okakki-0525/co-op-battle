# 協力バトル PV仕様書

## 目的

YouTube Shorts向けPVを制作する。

## 基本仕様

-   1080×1920（9:16）
-   約30秒
-   30fps
-   MoviePy + Pillow + numpy

## 構成

### 0～3秒

-   敵画像を高速切替
-   「戦闘だけのブラウザゲーム！」
-   「無料ですぐ遊べる！」

### 3～6秒

-   「オンラインで仲間と協力！」

### 6～8秒

-   「全員のコマンドが揃ったら、一斉に行動！」
-   勇者：炎剣 ✓
-   タンク：フォートレス ✓
-   魔術師：マジックブースト ✓
-   ACTION!!

### 8～10秒

-   戦闘開始演出

### 10～25秒

-   協力バトル風戦闘
-   ダメージ目安
    -   通常20～40
    -   炎剣50～90
    -   強攻撃100～180
    -   被ダメ20～80

### 25～30秒

-   協力バトルONLINE
-   最大6人で協力バトル！
-   仲間と連携して強敵を倒せ！
-   URL
-   QRコード
-   今すぐ無料でプレイ！

## QRコード

co_op_battle_qr.png を使用する。
